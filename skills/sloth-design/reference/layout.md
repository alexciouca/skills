# Layout

Fix spacing, grouping, grid and rhythm on the target, so the eye knows where
to go and what belongs together.

**Keeps:** content, components, visual identity, the order of the main task.
**May change:** spacing, widths, alignment, grid, grouping, section order
within the target when it clearly helps the task (say so).

## Steps

1. **Squint test.** Look at the screenshot blurred or zoomed out. What stands
   out first? What clumps together? That is what the user sees; fix that.
2. **Spacing scale.** Find the values in use; map them to one scale (the
   project's, or 4/8-based: 4, 8, 12, 16, 24, 32, 48, 64, 96). Space inside a
   group smaller than the space between groups, every time.
3. **Grouping.** Proximity first, then alignment, then a subtle background,
   and a border or card only when the others aren't enough. A card is a
   container for one thing a user can act on, not a default wrapper.
4. **Grid and alignment.** A few strong alignment lines beat many weak ones.
   Pick content widths on purpose (reading text about 65ch; app content as
   wide as the data needs). Left-aligned by default; center only short,
   standalone things.
5. **Rhythm.** Vary section size and density on purpose: not every block the
   same height with the same gap. Big gaps mark big changes.
6. **Responsive.** Let breakpoints come from where the content breaks, not
   from device names. On small screens stack in reading order, keep the
   primary action reachable, and cut space before cutting content.
7. **Hierarchy.** One focal point per view; the primary action is easy to
   find without hunting.

## Mode notes

- **Work:** consistency and density; align forms and tables to a shared grid;
  keep navigation and actions where users expect them.
- **Sell:** one idea per section; generous space around the main claim and
  action; asymmetry is allowed.
- **Read:** a comfortable column, clear section breaks, side navigation that
  doesn't crowd the text.
- **Show:** the work sets the grid; frames and chrome as thin as possible.

## Default tells to fix

Everything in a card; every section centered at the same width; equal gaps
everywhere; a grid of identical tiles where the content isn't identical.

Report the scale, the main alignment and grouping changes, and before/after
screenshots.
